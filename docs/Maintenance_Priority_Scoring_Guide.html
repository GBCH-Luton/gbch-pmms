How the system decides whether a ticket is Critical, Urgent, or Routine — and where today's setup quietly under-reacts to serious problems.

The fix principle

A category's fallback score should never be lower than its own mildest listed issue. If we genuinely don't know what's wrong, the system should assume it's at least as serious as the mildest known thing that can go wrong in that trade — never less. This is easy to explain, easy to audit, and needs no subjective re-judging of each category.

A known limitation

This rule protects against the mildest known issue in a category, not the worst. Utilities & Supply spans a mild "Smart meter installation" (65) up to a severe "Gas supply issue" (130) — the fallback can only be as cautious as the mildest of those. The lasting fix for that gap is keeping the specific-issue list comprehensive enough that "unlisted" is rarely picked for something genuinely serious.

Nothing has been changed in the live system. Once agreed, updating these numbers in Settings → Maintenance Categories takes a few minutes.
